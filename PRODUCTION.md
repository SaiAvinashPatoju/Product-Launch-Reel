## File naming

Use descriptive names such as `exvisit-launch-styleframes-v01.pdf`, `exvisit-launch-animatic-v01.mp4` and `exvisit-launch-master-v01.mp4`. Version numbers identify review passes, not approval.

Commit related document and asset changes together with a clear description. Put larger project files and recordings in the agreed shared storage, with a link and version recorded in the relevant folder's README. Never place credentials or signed private download URLs in this repository.
